# CANDYcrous
découverte du C++ dans le cadre d'une SAé de développement.

## Objectif
réaliser un jeu s'exécutant dans le terminal copiant les principes du fameux jeu de King, Candy Crush Saga (https://www.king.com/fr/game/candycrush).

## Demande
fournir une interface claire et minimaliste dans le terminal, avec des couleurs et des informations utiles.
